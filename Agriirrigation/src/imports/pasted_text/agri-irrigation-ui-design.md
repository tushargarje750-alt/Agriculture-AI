Design a modern, clean, and professional **AgriTech web platform UI** called **“Agri-Irrigation”**.
This platform is a smart farming system that uses IoT sensors, AI irrigation models, and farm monitoring tools to help farmers manage their farms efficiently.

The interface should feel **modern, minimal, technology-driven, and farmer-friendly**. Use an agriculture inspired design language with green accents, clean typography, rounded components, and soft shadows.

The platform must support **Light Mode and Dark Mode**, and include a **theme toggle switch in the navigation bar**.

The design must be **fully responsive**, optimized for desktop, tablet, and mobile screens.

---

### 1. Landing Page

Create a modern landing page introducing the Agri-Irrigation platform.

Sections should include:

Hero Section

* Headline: “Smart Irrigation for the Future of Farming”
* Short description about AI powered irrigation and smart farm monitoring
* Illustration of smart farming with IoT sensors
* Primary button: “Get Started”

Feature Section
Display 5 key features in card layout:

* Smart Irrigation Automation
* Soil Fertility Analysis
* Solar Powered Farm Devices
* AI Assistant for Farmers
* Plant Disease Detection

How It Works Section
Show a simple flow diagram:
Sensors → IoT Device → Cloud → Dashboard → Smart Decisions

Footer

* About
* Contact
* Documentation
* Support

---

Login Page

Desktop:

* Sidebar navigation with dashboard layout

Tablet:

* Collapsible sidebar

* Stacked layout for charts and maps

Use a modern AgriTech SaaS design style.

Design elements:

* Green accent colors

* Dark mode variant
* Rounded cards
* Soft shadows
* Smooth spacing
* Modern data charts
